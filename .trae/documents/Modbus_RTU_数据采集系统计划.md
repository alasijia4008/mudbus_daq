# Modbus RTU 数据采集上位机系统开发计划

## 系统概述
开发一个基于 Modbus RTU 协议的数据采集上位机系统，具备以下核心功能：
- Modbus RTU 通信（读写保持寄存器）
- 实时数据曲线显示
- 数据保存到文件（CSV/Excel）
- 用户友好的图形界面

## 技术选型
- **编程语言**: Python 3.x
- **GUI框架**: PyQt5（成熟的桌面应用框架）
- **Modbus库**: pymodbus（支持Modbus RTU/TCP）
- **数据可视化**: PyQtGraph（高性能曲线绘制）
- **数据存储**: pandas + openpyxl

## 实施步骤

### 第一阶段：项目基础架构
1. 创建项目目录结构
   ```
   modbus_daq_system/
   ├── main.py                 # 主程序入口
   ├── ui/                     # UI模块
   │   ├── main_window.py     # 主窗口
   │   └── widgets/           # 自定义控件
   ├── communication/         # 通信模块
   │   └── modbus_handler.py  # Modbus通信处理
   ├── data/                  # 数据处理模块
   │   ├── data_manager.py    # 数据管理
   │   └── data_saver.py      # 数据保存
   └── utils/                 # 工具模块
   ```

2. 创建虚拟环境和安装依赖
   ```bash
   python -m venv venv
   pip install pymodbus pyqt5 pyqtgraph pandas openpyxl
   ```

### 第二阶段：UI界面开发
3. 实现主窗口 (main_window.py)
   - 串口参数配置区（端口、波特率、数据位、停止位、校验位）
   - Modbus参数配置区（从机地址、寄存器地址、寄存器数量）
   - 连接/断开按钮
   - 数据展示表格
   - 实时曲线显示区域
   - 数据保存控制（开始/停止保存、文件路径）

4. 创建自定义控件
   - 曲线显示widget（使用PyQtGraph）
   - 数据表格widget

### 第三阶段：Modbus通信实现
5. 实现ModbusHandler类 (modbus_handler.py)
   - 串口连接/断开管理
   - 读取保持寄存器功能 (Function Code 03)
   - 写入单个寄存器功能 (Function Code 06)
   - 写入多个寄存器功能 (Function Code 16)
   - 异常处理和重连机制
   - 数据回调机制（将数据传递给UI）

### 第四阶段：数据处理与保存
6. 实现DataManager类 (data_manager.py)
   - 维护采集数据的内存缓存
   - 数据预处理和格式化
   - 支持多个寄存器同时采集
   - 数据时间戳管理

7. 实现DataSaver类 (data_saver.py)
   - CSV格式保存
   - Excel格式保存（支持大数据量）
   - 自动创建带时间戳的文件名
   - 保存状态指示

### 第五阶段：曲线显示功能
8. 实现实时曲线显示
   - 使用PyQtGraph进行高性能渲染
   - 支持多通道数据显示
   - 曲线滚动显示（固定时间窗口）
   - 坐标轴自动缩放
   - 曲线颜色区分

### 第六阶段：功能集成与测试
9. 集成测试
   - 串口连接测试
   - Modbus读取测试
   - 数据保存测试
   - 曲线显示测试

10. 完善异常处理
    - 串口断开重连
    - 通信超时处理
    - 数据格式错误处理

## 关键功能详细设计

### 串口配置参数
| 参数 | 选项 |
|------|------|
| 端口 | COM1-COM256 |
| 波特率 | 1200, 2400, 4800, 9600, 19200, 38400, 57600, 115200 |
| 数据位 | 7, 8 |
| 停止位 | 1, 1.5, 2 |
| 校验位 | 无, 奇校验, 偶校验 |

### Modbus读取配置
| 参数 | 说明 |
|------|------|
| 从机地址 | 1-247 |
| 寄存器地址 | 0-65535 |
| 寄存器数量 | 1-125 |
| 采集周期 | 100ms - 10000ms |

### 数据表格显示
- 寄存器地址
- 寄存器值
- 数据类型（INT16, UINT16, INT32, FLOAT等）
- 更新时间
- 变化趋势指示

### 曲线显示
- X轴：时间（可滚动）
- Y轴：寄存器值（自动缩放）
- 支持同时显示多个寄存器曲线
- 图例说明
- 网格线

### 数据保存格式
CSV格式：
```csv
时间,寄存器地址1,寄存器地址2,...
2026-05-01 10:00:00,100,200,...
```

## 验证方式
1. 使用Modbus Slave模拟器进行测试
2. 使用实际的Modbus设备进行验证
3. 测试数据保存文件的正确性
